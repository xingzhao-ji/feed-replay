# Public export provenance

The C++ source/headers, Python scripts, product tests, independent reference and literal fixtures are byte-identical copies of the accepted project, except for the later edits noted below. The Makefile uses a standalone Python default. README setup/status and the already reviewed exit-code clarification are documentation-only changes. No new protocol behavior or timing study was introduced for publication.

Private workflow notes, absolute user/workspace paths and local bytecode/cache files are excluded or normalized. Historical evidence/review files whose paths changed are explicitly public export copies. Their embedded historical hashes identify original private evidence, not rewritten public files. `PUBLICATION-MANIFEST.json` records each public file of the first export, its original hash where applicable, transformations and exclusions. Later documentation edits removed review records and local paths, so some files it lists are gone or differ from its hashes. The cache directory default was renamed after the manifest was made, so the hashes for `Makefile`, `scripts/guard.py`, `scripts/benchmark_report.py`, `scripts/evidence_index.py`, `tests/test_cli.py` and `tests/test_codec.py` differ. The scope wording that `scripts/render_report.py` writes into `docs/results.md` and `evidence/report.html` was also edited, so its hash differs too. Original private files remain unchanged.

The original pre-implementation `review/freeze-v1.json`, its nine reference files and the full synthetic workload remain byte-identical. Consequently the original freeze and workload integrity checks still apply. Historical review commands may use the original workspace-relative location; from this repository root use `python3 review/test_reference.py`. Old pending-review wording in historical checkpoints is superseded.

Only synthetic authored wire captures, fixtures, weights-free workload records and expected outputs are distributed. No live exchange feed, customer data, credentials or Nasdaq specification PDFs are included. The technical documents link the official Nasdaq specifications; their cached originals are not vendored. pytest and its dependencies are obtained separately from upstream distributions and retain their own licenses. No project LICENSE file was present; this export does not invent an open-source license grant.

Publication verification uses a separate Python virtual environment populated by copying already installed pytest distributions, and a new build/runtime cache. This is isolated-source packaging verification with the installed macOS/Clang/SDK, not a clean-machine or new dependency-installation claim. Existing normal/sanitized tests exercise bounded loopback UDP and correctness-only benchmark checks. No new timing samples are collected. The retained sparse-query loss to scanning, macOS-specific exclusive publication, subset semantics, unauthenticated peer pinning and local/synthetic limits remain visible.
